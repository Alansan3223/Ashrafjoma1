# ע.ל.נ — קטלוג שתלים וציוד דנטלי

קטלוג לנייד בשביל מרפאות שיניים: מוצרים לפי קטגוריות, חיפוש לפי שם או מק"ט, בחירת מידות וכמות, ושליחת הזמנה מסודרת לוואטסאפ.
אפשר להשתמש בו בעברית ובערבית, ובכניסה הראשונה מופיע אישור "לאנשי מקצוע בלבד".

## עריכה
- **מוצרים:** בקובץ `products.js`. המוצרים שם הם **דוגמאות**, ויש להחליף אותם בשמות, במק"טים ובמידות האמיתיים של היצרן.
- **פרטי העסק, הוואטסאפ, הצבעים והצגת המחירים:** בקובץ `config.js`. אם `showPrices: false`, מוצג "מחיר לפי הצעה".
- **לוגו:** `assets/logo.svg`.

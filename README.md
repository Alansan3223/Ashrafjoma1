# ASHRF Remas Tours — אפליקציית איתור מקומות תיירות

אפליקציה לנייד (PWA, מותקנת מהדפדפן לאייפון ולאנדרואיד) למציאת אטרקציות, מסעדות, בתי קפה, מלונות, טבע וחופים, קניות ומקומות קדושים **בכל מדינה בעולם**.

## מה יש באפליקציה
- **חיפוש יעד** — עיר, מדינה או מקום, או כפתור **"סביבי"** לפי מיקום GPS.
- **בחירת מדינה** — כל מדינות העולם עם דגלים, ורשימת הערים הגדולות בכל מדינה.
- **7 קטגוריות** ובחירת רדיוס (1/3/10/25 ק"מ).
- **כרטיס מקום** — שם, סוג, כתובת (גם כשאין כתובת במפה, היא מאותרת אוטומטית), קואורדינטות, שעות פתיחה, טלפון, אתר וויקיפדיה.
- **איך מגיעים** — מרחק וזמן משוער ממך, וקישורי ניווט ל-Google Maps (תחבורה ציבורית/הליכה), Moovit, Waze ו-Apple Maps.
- **תחבורה ציבורית ליד המקום** — תחנות אוטובוס, רכבת, מטרו, חשמלית ומעבורת הקרובות, עם מרחק, דקות הליכה **ומספרי הקווים** שעוצרים בהן, וגם על מפה קטנה.
- **מפה** של כל התוצאות, **מועדפים** ששמורים בטלפון, ו**שיתוף** מקום בקישור.
- **3 שפות**: עברית, ערבית ואנגלית.
- **מיתוג העסק** — לוגו, צבעים, וכפתורי וואטסאפ/טלפון/מייל/פייסבוק/טיקטוק. בכל מקום יש כפתור "רוצים שנארגן לכם טיול?" שפותח וואטסאפ עם הודעה מוכנה.

הנתונים מגיעים בזמן אמת מ-OpenStreetMap (חינמי, ללא מפתח API).

## הלוגו
`assets/logo.svg` הוא שחזור וקטורי של הלוגו מכרטיס הביקור. כדי להשתמש בקובץ המקורי שמרו אותו בשם `assets/logo.png`, והאפליקציה תציג אותו אוטומטית.
אייקוני ההתקנה נמצאים ב-`assets/icon-*.png`.

## שינוי פרטי העסק
כל הפרטים נמצאים בקובץ אחד, `config.js`: שם, סלוגן, צבעים, טלפונים, וואטסאפ, מייל, כתובת, פייסבוק וטיקטוק.

## העלאה לאוויר (חינם)
**GitHub Pages:** במאגר נכנסים ל-Settings → Pages → Source: *Deploy from a branch*, בוחרים את הענף ואת התיקייה `/ (root)`. אחרי דקה תתקבל כתובת כמו `https://<user>.github.io/Ashrafjoma1/`.
אפשר גם להעלות את התיקייה כמו שהיא ל-Netlify או ל-Vercel.

> חובה להעלות לכתובת **https** (GitHub Pages כבר עושה את זה), כי בלי https לא יעבדו המיקום וההתקנה.

## התקנה בטלפון
- **אייפון (Safari):** כפתור שיתוף ← "הוסף למסך הבית".
- **אנדרואיד (Chrome):** תפריט ⋮ ← "התקן אפליקציה".

## הוצאה לחנויות (Google Play / App Store)
אפשר לארוז את האתר כאפליקציה לחנויות באמצעות [PWABuilder](https://www.pwabuilder.com): מזינים את כתובת האתר ומורידים חבילה לאנדרואיד ול-iOS. נדרש חשבון מפתח בכל חנות.

## הערה לשימוש בהיקף גדול
שרתי Overpass ו-Nominatim הציבוריים חינמיים ומיועדים לשימוש מתון. אם יהיו הרבה משתמשים, כדאי לעבור לספק בתשלום (למשל Geoapify, MapTiler או LocationIQ) או לשרת פרטי.
